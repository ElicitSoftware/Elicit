Elicit default brand: which navy is primary?

The Choice E mark is drawn in the darkest navy #0A3D62 and green #22775D. The applications' primary color today is the lighter Ink #1B629C. The same screens are shown twice below; only the primary color and its hover step differ. Green, neutrals and status colors are the same on both sides.
